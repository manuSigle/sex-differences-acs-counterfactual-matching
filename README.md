# Sex differences in prehospital suspected ACS

This repository contains the analysis code accompanying the manuscript:

"Sex differences in prehospital suspected acute coronary syndrome via counterfactual digital-twin matching"

The notebook includes code for:
- preprocessing and missing data handling
- Gower distance calculation
- opposite-sex counterfactual matched-pair construction
- covariate balance assessment
- paired statistical analyses
- sensitivity analyses across Gower distance thresholds

## Data availability

The underlying patient-level data are not publicly available due to data protection and ethics restrictions. The datasets analyzed during the current study are available from the corresponding author upon reasonable request and contingent on approval by the local ethics committee.
